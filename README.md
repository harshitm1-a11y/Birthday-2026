# A Universe Made Just For You ✨ — Sameeksha's 3D Birthday Universe

An interactive, responsive 3D birthday experience created for **Sameeksha** (23 November 2026).

## 🌟 Live Demo
- **URL**: [https://sameeksha-birthday.embarko.app](https://sameeksha-birthday.embarko.app)

---

## 🚀 Features

### 🌌 7 Connected Interactive Scenes
1. **Galaxy Welcome**:
   - 3D procedural starfield with rotating celestial glowing heart and stardust particles.
   - Cinematic entry into the universe.
   - Hidden Heart collectible #1.

2. **The Magical Gift**:
   - 3D gift box with interactive drag-to-rotate OrbitControls.
   - Ribbon & lid opening animation with particle bursts and golden sparkles.
   - Hidden Heart collectible #2.

3. **Our Little Memories**:
   - Curated memory gallery featuring authentic photos in floating polaroid styling.
   - Interactive high-resolution modal with swipe, arrow keys, and keyboard navigation.
   - Hidden Heart collectible #3.

4. **Your Little Companion**:
   - Original 3D robot/mascot with procedural idle floating bob and bounce animations.
   - Interactive speech bubble with 5 sweet Hinglish dialogues.
   - Hidden Heart collectible #4.

5. **Make a Wish (Birthday Cake)**:
   - 2-tier 3D birthday cake with glowing "SAMEEKSHA" plaque.
   - 5 realistic flickering candle flames with point lights.
   - Interactive "Blow the Candles" button extinguishing flames with celebration confetti & fireworks bursts.

6. **A Letter From The Heart**:
   - Elegant glowing parchment letter with real typewriter animation and blinking cursor.
   - Full Hinglish emotional birthday message with instant "Skip Typing" option.
   - Fully selectable and accessible typography.

7. **Grand Finale & Compliment Garden**:
   - Grand celebration with fireworks and shimmering particles.
   - Replay and quick scene-navigation buttons.
   - **Compliment Garden**: 6 interactive blooming flowers (🌸, 🌺, 🌻, 🌷, 🌹, 💐) revealing personalized Hinglish compliments.
   - Hidden Heart collectible #5: Unlocks the **Secret Message Modal** when all 5 hearts are collected!

---

## 🛠 Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations**: Framer Motion, GSAP, CSS Animations
- **State Management**: Zustand
- **Audio**: Web Audio API ambient synthesizer & celebratory chimes (opt-in)
- **Deployment**: Embarko Cloud Hosting
